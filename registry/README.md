# Registry

The registry is the source of truth for content-level guide topic coverage and
verified publication state.

- Canonical file: `editorial-guide-registry.md`
- Read it before choosing a topic.
- Judge overlap by coverage signature: specific place, event or festival type,
  route, ticket, pass, permit, rule, traveler decision, category, and slug
  keywords. Country and city are metadata, not duplicate keys.
- Update it immediately after production admin API verification changes a guide
  from queued work to published state.
- Do not infer state from generated files. Use production API verification.
