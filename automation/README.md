# Manual Support Contracts

Recurring guide automations have been removed. This directory now keeps only
shared contracts that are still useful during mobile/chat-driven work.

Active shared files:

- `shared/environment.yaml`: local path, API base URL, language set, and quality
  gate names. It does not define an active schedule.
- `shared/admin-articles-api.md`: production admin articles API contract.
- `shared/article-writing-standard.md`: readable guide and localization standard.
- `shared/content-repair-workflow.md`: content-only review and repair workflow.

Removed from active context:

- scheduled task prompts
- task workflows and runbooks
- role-agent prompt files
- automatic git-persistence task docs

Use `prompts/mobile-chat.md` for how to start work from mobile.
