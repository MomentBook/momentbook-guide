# docs/ai

This folder stores **one short summary per AI-assisted task**.

Rules:
- 1 file per task max: `YYYY-MM-DD_<topic>.md`
- Keep it short:
  1) What changed
  2) Why
  3) Files deleted/added
  4) Risks/TODO

Note:
- These are **historical task logs**, not the source of truth.
- Older entries may describe superseded intermediate states, removed routes, or deleted modules.
- For current codebase alignment, read the latest refresh log in this folder only after checking the canonical docs.
- For canonical decisions, read `docs/PRODUCT.md` and `docs/adr/*`.
